- Final Quality Gate

## 핵심 원칙

- Google 검색 순위·트래픽을 보장하지 않는다.
- 알고리즘 우회·조작을 목표로 하지 않는다.
- 사람 중심의 유용하고 신뢰할 수 있는 콘텐츠를 우선한다.
- AI 사용 자체가 아니라 저가치·반복·대량 생성 패턴을 검사한다.
- 원문 복제·스크래핑·단순 재작성 콘텐츠를 피한다.
- 실제 경험이 없는 내용을 경험담처럼 작성하지 않는다.
- 키워드 도배·숨은 텍스트/링크·클로킹·도어웨이·링크 스팸 등을 차단한다.
- 광고·제휴·스폰서 링크는 적절한 표시와 링크 속성을 검토한다.
- 개인정보와 허위·과장 정보를 발행 전에 검사한다.
