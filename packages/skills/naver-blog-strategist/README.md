# Naver Blog Strategist Skill Module

BlogMaster AI에서 네이버 블로그 콘텐츠 제작 Workflow가 사용할 수 있도록 `naver-blog-strategist` 스킬을 모듈화한 영역이다.

## Current Engine

- `NAVER Content Intelligence Skill v2.0`
- 검색 의도 분석
- 키워드 자연성 분석
- 최신 정보 조사 및 출처 검증
- 사실/의견/추정/경험 구분
- 실제 경험 여부 검증
- 콘텐츠 품질 점수
- 스팸·키워드 도배·개인정보·광고/협찬 위험 검사
- 발행 전 Final Quality Gate

## Operations

- `keyword_strategy`: 메인/연관/롱테일 키워드와 검색 의도 정의
- `research`: 최신 정보 조사 및 출처 검증
- `experience_check`: 실제 경험을 가장하는 표현 검사
- `title_thumbnail_hook`: 제목·썸네일·도입 후킹 생성
- `draft`: 본문 초안 생성
- `quality_gate`: Master AI 내부 콘텐츠 품질 점검
- `safety_guard`: 스팸·개인정보·광고·허위/과장 위험 점검
- `revise`: 점검 결과를 반영한 보완
- `publish_package`: 본문·이미지 가이드·CTA·태그·출처·품질·안전 결과를 묶은 발행 패키지 생성

## 품질 게이트

품질 점수는 네이버 실제 검색 알고리즘 점수가 아니다. 검색 순위나 상위 노출을 보장하지 않는다.

기본적으로 중대한 안전 문제가 있으면 발행을 보류하고, 품질 개선이 필요한 경우 수정 단계를 거친다.

## 원칙

- 검색 순위·조회수·팔로워 증가를 보장하지 않는다.
- 검색 알고리즘 우회나 조작을 목적으로 하지 않는다.
- 최신 정보는 가능한 공식 출처를 확인한다.
- 경험하지 않은 내용을 직접 경험한 것처럼 작성하지 않는다.
- 키워드 도배·숨은 키워드·무관한 인기 키워드 삽입을 하지 않는다.
- 광고·협찬·제휴는 필요한 표시 여부를 확인한다.
- 개인정보와 허위·과장 표현을 발행 전에 검사한다.
- AI 사용 여부를 숨기기 위한 위장 기술이 아니라 독자에게 유용하고 자연스러운 콘텐츠를 만드는 것을 목표로 한다.
