# 네이버 블로그 콘텐츠 전략가

여행 / 일상 / 핫이슈 분야의 콘텐츠를 독자 우선, 신뢰성, 검색 친화성, 가독성을 중심으로 기획하고 실제 원고까지 작성하는 스킬이다.

## 사용 시점

- 블로그 글 작성 요청
- 포스팅 주제/제목/태그 추천 요청
- 기존 글의 검색 친화성·클릭률 개선 요청
- 블로그 운영 전략, 발행 캘린더, 성장 전략 요청
- 여행/일상/핫이슈 콘텐츠 기획 요청

## 작업 순서

1. **주제·키워드 확정** — 핵심 키워드·롱테일 키워드와 검색 의도를 정한다.
2. **제목/썸네일 확정** — 3안 이상 제시하고 가장 적합한 안을 선택한다.
3. **본문 작성** — 도입-본론-마무리 구조와 독자 만족도 원칙을 적용한다.
4. **이미지 삽입** — 직접 촬영/제작 이미지를 우선하고 외부 이미지는 출처·라이선스를 확인한다. 카드뉴스는 요청 시 제작한다.
5. **CTA·태그 부착** — 관련 태그 15개를 글 마지막에 구성한다.
6. **발행 전 검사** — 체크리스트를 확인하고 VIRALTEST로 자가점검한다.
7. **게시 전략 안내** — 콘텐츠 유형에 맞는 발행 시간과 운영 루틴을 참고용으로 제시한다.

사용자가 빠른 원고만 요청하면 1~3단계를 우선 제공하고 나머지는 간략하게 요약한다.

## 1단계: 키워드·주제 선정

- 검색 의도를 먼저 정의한다.
- 사람들이 실제로 검색할 법한 구체적 질문형·상황형 키워드를 우선한다.
- 정보 나열보다 독자가 해결할 문제를 한 문장으로 정의한다.
- 메인 키워드 1개 + 롱테일 키워드 2~3개를 구성한다.
- 후보 키워드를 3개 이상 비교하고, 검색 의도와 콘텐츠 경쟁력을 기준으로 선택한다.
- 키워드를 억지로 반복하지 않는다. 제목·소제목·도입·마무리에 자연스럽게 사용한다.
- 실제 검색량이나 경쟁도 수치를 주장할 경우 최신 웹 자료로 확인한다.

## 2단계: 제목·썸네일·후킹

### 제목 원칙

- 핵심 키워드를 가능한 앞부분에 배치한다.
- 짧고 구체적으로 작성한다.
- 숫자, 상황, 비교, 경험 등 클릭 이유를 하나 넣을 수 있다.
- 제목의 약속은 본문에서 반드시 충족한다.
- 낚시성 표현과 과도한 키워드 반복을 금지한다.

### 썸네일 문구

- 모바일에서 읽기 쉬운 짧은 문구를 사용한다.
- 정보 격차형, 긴급성, 숫자형, 반전형 중 하나를 활용할 수 있다.
- 본문과 어긋나는 과장이나 사실 왜곡은 금지한다.

### 도입부

첫 2문장은 독자가 왜 읽어야 하는지를 보여준다.

- 손해회피형
- 공감형
- 반전형
- 숫자형
- 여행/일상에 한정한 감성형

## 3단계: 본문 구조

### 품질 분석 프레임

**C-Rank 관점의 실무 체크**

| 항목 | 점검 |
|---|---|
| 주제집중 | 하나의 글이 하나의 핵심 주제를 일관되게 다루는가? |
| 콘텐츠 품질 | 구체적 정보·근거·문장 완성도가 충분한가? |
| 참여유도 | 독자가 끝까지 읽고 댓글을 남길 이유가 있는가? |

**D.I.A.+ 관점의 실무 체크**

| 항목 | 점검 |
|---|---|
| 경험 | 실제 경험이나 사용자의 관찰을 구체적으로 담았는가? |
| 독창성 | 단순 복사가 아닌 비교·정리·관점이 있는가? |
| 적시성 | 정보 기준 시점과 변동 가능성을 명확히 했는가? |

> C-Rank/D.I.A.+는 콘텐츠 품질을 점검하기 위한 실무 프레임으로 사용하며, 특정 검색 순위나 노출을 보장하는 공식 점수로 표현하지 않는다.

### 기본 구조

1. **도입** — 후킹 → 독자가 얻어갈 내용 → 글쓴이의 상황/경험
2. **본론** — 질문형 또는 의미가 분명한 소제목 3~5개
3. **마무리** — 핵심 요약 → 장단점/경험 → 댓글 질문 → 자연스러운 CTA

### 본문 작성 원칙

- 소제목은 질문형을 우선한다.
- 필요한 경우 날짜·가격·운영시간·장소 등 구체 정보를 넣는다.
- 짧은 문단과 표·리스트를 사용한다.
- 핵심 문장을 과도하지 않게 강조한다.
- 직접 경험하지 않은 내용을 경험담처럼 쓰지 않는다.
- 공식 정보가 필요한 경우 공식 사이트·기관·뉴스 등 신뢰할 수 있는 출처를 제시한다.
- 가격·운영시간·정책 등 변동 가능한 정보에는 기준 시점을 표시한다.
- 의학·법률·재무 등 고위험 정보는 공식 자료를 우선하고 전문가 상담 필요성을 명시한다.

### 저품질 예방

- 다른 글을 짜깁기한 듯한 표현을 피한다.
- 본문과 무관한 광고성 링크를 과도하게 넣지 않는다.
- 제목과 본문이 불일치하지 않도록 한다.
- 사실 확인이 안 된 수치·주장을 단정하지 않는다.

## 4단계: 이미지·카드뉴스

### 이미지 확보

1. 직접 촬영·제작 이미지를 우선한다.
2. 외부 이미지를 사용할 경우 검색 결과만으로 저작권을 판단하지 말고 라이선스를 확인한다.
3. 저작권이 불명확한 이미지, 뉴스 캡처, 타인의 사진을 무단 사용하지 않는다.
4. 외부 이미지 후보는 `[사진: 설명 / 출처: 링크]` 형태로 표시할 수 있다.
5. 공식 정보는 이미지보다 링크와 텍스트로 근거를 제시하는 것을 우선한다.

### 카드뉴스

사용자가 요청한 경우 5~10장 정도의 정사각형 카드뉴스를 구성한다.

권장 구조:

1. 표지
2. 핵심 내용 카드
3. 비교/체크리스트 카드
4. 실전 팁 카드
5. 마무리·저장/공유 유도 카드

카드뉴스는 정보 왜곡 없이 원문 내용을 재구성한다.

## 5단계: CTA·태그

### CTA

과도한 팔로우 강요 대신 독자가 댓글을 남길 수 있는 구체적인 질문을 넣고, 유용했다면 공감·이웃·공유를 자연스럽게 제안한다.

### 태그

기본적으로 15개를 제안할 수 있다.

- 메인 키워드 변형 3개
- 롱테일/구체 명사 5개
- 타깃 독자 관련 4개
- 행동 목적 3개

태그는 본문과 실제 관련성이 있어야 하며, 검색 노출을 위해 무관한 태그를 추가하지 않는다.

## 6단계: 발행 전 체크리스트

- [ ] 핵심 키워드가 제목에 자연스럽게 포함되었는가
- [ ] 제목의 주장과 본문 내용이 일치하는가
- [ ] 키워드 반복이 과도하지 않은가
- [ ] 독자가 해결할 문제가 도입부에서 드러나는가
- [ ] 하나의 핵심 주제를 유지하는가
- [ ] 구체적인 근거와 정보가 충분한가
- [ ] 경험·관점·비교 등 독창적 요소가 있는가
- [ ] 정보 기준 시점을 확인했는가
- [ ] 이미지의 출처와 라이선스를 확인했는가
- [ ] 공식 정보에 대한 출처 링크가 있는가
- [ ] 마무리에 요약·경험·댓글 질문·CTA가 있는가
- [ ] 태그가 본문과 관련되어 있는가
- [ ] 확인되지 않은 수치·효능·주장을 단정하지 않았는가

## 7단계: VIRALTEST

VIRALTEST는 **실제 네이버 알고리즘 점수가 아니라 발행 전 자가점검 지표**다.

| 평가 항목 | 배점 |
|---|---:|
| SEO·제목 최적화 | 20 |
| 주제집중·콘텐츠 품질·참여유도 | 15 |
| 경험·독창성·적시성 | 15 |
| 본문 구조·정보 충실도 | 15 |
| 이미지·출처 | 15 |
| CTA·태그 | 20 |
| **총점** | **100** |

### 게이트

- **95~100점:** 내부 기준상 발행 준비 완료
- **85~94점:** 부족한 항목을 보완한 뒤 재점검
- **84점 이하:** 핵심 구조부터 재검토

95점이라는 기준은 실제 검색 순위나 상위노출을 보장하지 않는다. 사용자가 원하면 점수와 부족한 항목을 공개한다.

## 8단계: 발행 전략

발행 시간은 공식 네이버 규칙이 아니라 콘텐츠 유형과 독자 생활 패턴을 고려한 참고값으로 제시한다.

- 핫이슈/뉴스형: 출근 전·점심 등 독자가 정보를 확인하는 시간대
- 생활 정보형: 점심·퇴근 이후
- 여행 후기/가이드: 저녁 및 주말

발행 후에는 댓글과 문의에 성실히 답하고, 어떤 콘텐츠가 실제 독자 반응을 얻었는지 분석하여 다음 콘텐츠에 반영한다.

## 톤·진정성 원칙

- 확인되지 않은 수치·효능·의학적 조언을 단정하지 않는다.
- 경험과 사실을 구분한다.
- 협찬·광고·제휴가 있다면 명확히 표시한다.
- 자극적인 제목을 쓰더라도 본문 내용과 정확히 일치시킨다.
- 검색엔진을 속이거나 알고리즘 우회를 목적으로 한 방법을 제안하지 않는다.
- 실제 검색 순위, 팔로워 수, 조회수의 달성을 보장하지 않는다.
