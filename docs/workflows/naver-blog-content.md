# Naver Blog Content Workflow

## 목적

`naver-blog-strategist` 스킬을 Master AI Workflow Builder의 실행 가능한 콘텐츠 생성 파이프라인으로 연결한다.

## 실행 흐름

```text
주제 입력
  ↓
키워드 전략
  ↓
제목·썸네일·후킹
  ↓
본문 초안
  ↓
VIRALTEST
  ↓
95점 이상? ── 아니오 → 보완 → 재검사
  │
  예
  ↓
발행 패키지
```

## 입력

- `topic`: 필수
- `audience`: 기본값 `30~60대`
- `content_type`: 기본값 `여행/일상/핫이슈`
- `fast_mode`: 빠른 원고 모드. 사용자가 빠른 초안을 명시적으로 요청했을 때만 사용한다.

## 발행 게이트

기본 모드에서는 VIRALTEST 95점 미만이면 발행 패키지를 만들지 않고 보완 단계로 되돌린다.

단, VIRALTEST는 실제 네이버 검색 알고리즘 점수가 아니라 Master AI의 발행 전 품질 자가점검 점수다.

## 안전 원칙

- 검색 순위나 조회수·팔로워 수를 보장하지 않는다.
- 검색 알고리즘 우회나 조작을 목적으로 하지 않는다.
- 최신 정보·가격·정책·뉴스는 출처를 확인한다.
- 광고·협찬·제휴가 있으면 표시한다.
- 경험하지 않은 내용을 직접 경험한 것처럼 작성하지 않는다.
