# BlogMaster AI 프로젝트 — 네이버 콘텐츠 모듈 지침

> 문서 버전: 1.0.0  
> 적용 대상: BlogMaster AI / Naver Content Module  
> 기준 스킬: `naver-blog-strategist`  

## 1. 프로젝트 목적

BlogMaster AI의 네이버 콘텐츠 모듈은 네이버 블로그 독자가 실제로 필요로 하는 정보를 중심으로 콘텐츠를 기획·작성·검수할 수 있도록 지원한다.

이 모듈의 목표는 검색엔진을 조작하거나 특정 순위를 보장하는 것이 아니라 **독자 만족도, 정보 정확성, 콘텐츠 충실도, 검색 친화성**을 높이는 것이다.

## 2. 적용 Skill

모든 네이버 블로그 콘텐츠 Workflow에는 다음 스킬을 기본 적용한다.

```text
naver-blog-strategist
```

Skill의 실행 작업은 다음과 같다.

1. `keyword_strategy` — 핵심 키워드, 롱테일 키워드, 검색 의도, 해결할 문제 정의
2. `title_thumbnail_hook` — 제목, 썸네일 문구, 도입 후킹 생성
3. `draft` — 본문, 이미지 위치, 출처, CTA, 태그 초안 생성
4. `viraltest` — 발행 전 품질 자가점검
5. `revise` — 부족한 항목 보완
6. `publish_package` — 발행 가능한 콘텐츠 패키지 구성

## 3. 기본 Workflow

```text
사용자 주제 입력
      ↓
키워드 전략
      ↓
제목·썸네일·후킹
      ↓
본문 초안
      ↓
VIRALTEST
      ↓
95점 이상인가?
   ┌──┴──┐
  아니오  예
   ↓      ↓
 보완    발행 패키지
   ↓
 재검사 ─────────┘
```

기본 모드에서는 VIRALTEST 95점 미만의 콘텐츠를 `publish_package` 단계로 통과시키지 않는다.

단, `fastMode`는 사용자가 빠른 초안을 명시적으로 요청한 경우에만 사용할 수 있으며, 빠른 초안은 최종 발행 검수를 대신하지 않는다.

## 4. 입력 계약

Skill 입력은 다음 Schema를 따른다.

- `topic`: 필수, 작성할 핵심 주제
- `audience`: 선택, 기본 `30~60대`
- `contentType`: `여행 | 일상 | 핫이슈 | 기타`, 기본 `여행`
- `keywords`: 선택, 사용자가 제공한 키워드 목록
- `fastMode`: 선택, 기본 `false`

정의 파일:

```text
packages/skills/naver-blog-strategist/schema.json
```

## 5. 콘텐츠 품질 원칙

### C-Rank 관점

- 하나의 글은 하나의 핵심 주제를 유지한다.
- 제목에서 약속한 내용을 본문에서 충분히 다룬다.
- 구체적인 정보와 근거를 사용한다.
- 댓글 질문 등 독자의 자연스러운 참여 요소를 제공한다.

### D.I.A.+ 관점

- 실제 경험과 확인된 정보를 구분한다.
- 단순 검색 결과 복사 대신 비교·정리·관점 등 독창성을 제공한다.
- 가격·운영시간·정책·뉴스 등 변동 정보는 기준 시점과 출처를 표시한다.

C-Rank와 D.I.A.+는 **실제 네이버 검색 알고리즘의 공식 점수나 공개된 상위노출 공식이 아니라**, BlogMaster AI 내부 콘텐츠 품질 점검 프레임으로 취급한다.

## 6. VIRALTEST 정책

VIRALTEST 총점은 100점이며 다음 항목을 사용한다.

| 항목 | 점수 |
|---|---:|
| SEO·제목 최적화 | 20 |
| 주제집중·콘텐츠 품질·참여유도 | 15 |
| 경험·독창성·적시성 | 15 |
| 본문 구조·정보 충실도 | 15 |
| 이미지·출처 | 15 |
| CTA·태그 | 20 |
| **합계** | **100** |

판정:

- 95~100: 발행 준비 완료
- 85~94: 보완 후 재검사
- 84 이하: 구조부터 재검토

VIRALTEST 점수는 검색 순위, 조회수, 팔로워 증가를 예측하거나 보장하는 지표가 아니다.

## 7. 이미지 및 출처

- 직접 촬영·제작 이미지를 우선한다.
- 외부 이미지는 출처와 라이선스를 확인한다.
- 저작권이 불명확한 이미지를 무단 사용하지 않는다.
- 공식 정보는 가능한 한 공식 기관·서비스의 원문을 출처로 사용한다.
- 최신 뉴스·가격·운영시간·정책 등은 작성 시점의 정보를 확인한다.

## 8. 제목 및 키워드 정책

- 핵심 키워드는 자연스럽게 제목에 포함한다.
- 키워드 반복으로 밀도를 인위적으로 높이지 않는다.
- 제목의 숫자·주장·약속은 본문에서 실제로 뒷받침한다.
- 낚시성 제목, 허위 과장, 근거 없는 수치 사용을 금지한다.

## 9. CTA 및 태그

CTA는 독자에게 유용한 정보를 제공한 뒤 자연스럽게 댓글·공감·이웃·공유를 제안한다.

기본 태그는 최대 15개 범위에서 실제 본문과 관련된 키워드만 사용한다. 검색 노출을 위해 무관한 태그를 추가하지 않는다.

## 10. 네이버 연동 범위

현재 BlogMaster AI의 네이버 모듈은 우선 **콘텐츠 기획·작성·검수·발행 패키지 생성**을 핵심 범위로 한다.

다음 기능은 별도 연동 모듈로 취급한다.

- 네이버 검색/트렌드 데이터 수집
- 네이버 공식 API를 통한 허용 범위의 연동
- 네이버 블로그 발행 자동화

네이버의 공식 정책과 제공 API 범위를 벗어난 자동화, 검색 순위 조작, 계정 행위 자동화는 구현하지 않는다.

## 11. 성장 전략 정책

BlogMaster AI는 `팔로워 100,000명`, `조회수 1,000,000회` 같은 목표를 **사업 목표 또는 콘텐츠 운영 목표**로 기록할 수 있으나 달성을 보장하는 문구를 생성하지 않는다.

성장 전략은 다음에 집중한다.

- 독자에게 실제 도움이 되는 콘텐츠의 지속적 발행
- 특정 주제에 대한 전문성과 일관성 축적
- 댓글과 피드백 분석
- 콘텐츠 성과 데이터 기반 개선
- 검색 의도와 독자 만족도 개선

## 12. 구현 규칙

Workflow Builder는 다음 계약을 사용한다.

```text
Workflow JSON
  ↓
Skill Loader
  ↓
naver-blog-strategist
  ↓
Operation 실행
  ↓
Quality Gate
  ↓
Publish Package
```

Workflow 정의:

```text
workflows/naver-blog-content.workflow.json
```

Skill Operation 정의:

```text
packages/skills/naver-blog-strategist/operations.json
```

## 13. 향후 구현 우선순위

1. Skill Loader 구현
2. Workflow Runner 구현
3. `naver-blog-strategist` Operation 실행기 구현
4. AI 모델 호출 계층 연결
5. VIRALTEST Validator 구현
6. BlogMaster AI 편집기와 연결
7. 네이버 데이터 연동 검토
8. 허용된 발행 연동 방식 검토

## 14. 금지 사항

- 네이버 검색 상위노출을 보장한다고 표현하지 않는다.
- 실제 알고리즘을 안다고 단정하지 않는다.
- 검색 알고리즘 우회·조작 방법을 구현하지 않는다.
- 허위 경험을 생성하지 않는다.
- 출처가 필요한 사실을 근거 없이 단정하지 않는다.
- 저작권이 불명확한 이미지를 자동 수집해 무단 사용하지 않는다.
- 광고·협찬·제휴 사실을 숨기지 않는다.

## 15. 제품 철학

> BlogMaster AI는 검색엔진을 속이는 도구가 아니라, **독자가 다시 찾고 싶은 콘텐츠를 더 빠르고 정확하게 만드는 제품**을 지향한다.
